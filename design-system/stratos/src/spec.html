Stratos

The competition is still in the valley.

This is the whole system: seven colours, three faces, one easing curve. Every value below is lifted from the live source — assets/css/chrome.css and assets/css/type.css — not from a brief. Where a brief and the build disagreed, the build won.

Self-contained: every typeface and image on this page is embedded. It makes no network requests and renders identically offline.

01 — Palette

Seven values. A black page, an off-white text, one beacon.

The palette is small on purpose. Everything that is not void, paper or signal is a step between them. There is no secondary accent, no tint ramp, and no colour that exists only to fill a slot in a table.

Void#000000

Page background. Upper atmosphere.

Ink#101010

Panel black. Raised surfaces on void.

Slate#232322

Brand near-black. Borders, inset wells.

Haze#757575

Secondary text, tick labels, metadata.

Paper#F4F4F4

Body text, and any surface that has to read as printed.

Signal#FFEE25

The beacon. Focus rings, the live altitude, one CTA per view.

Chrome#CBDCE9

Sampled from the chrome plane in the logo. The Meridian Trace.

Hairrgba(244,244,244,.14)

The only border colour. One hairline, everywhere.

Contrast

Paper on void 19.6:1 · Signal on void 15.9:1 · Chrome on void 12.4:1 · Haze on void 5.1:1

All four clear AA at every size; the first three clear AAA. Haze is the floor — nothing lighter than #757575 may carry text.

The signal rule

Signal is a foreground colour. It sets type, draws the focus ring, fills a small inverted button and lights the live section of the Trace. A paragraph on a full-bleed yellow panel is off-system — the beacon stops meaning anything the moment there is more than one of it on screen.

Grain

3.5% fractal noise, screen blend, six-step animation over 6s, fixed across the viewport. It is not decoration: it is what stops a pure-black page reading as an empty div. It is on this page right now.

Kinetic limits

Altitude drives type. These are the bounds every move is clamped to — stated once, so the engine can never ask for an axis value the font does not have.

weight    300 → 800      inside Archivo's 100–900
width     82% → 118%     inside Archivo's 62–125
tracking  −0.03em → 0.24em

Archivo's italic is a separate file, not an ital or slnt axis.
Roman → italic is a discrete swap, never an interpolation.
Discrete snap without overshoot. No liquid morphs.

Language

Hungarian is the source language, and display type carries Á É Ő Ű. Set leading loose enough that the accents do not collide with the line above — this is why the stage headings run looser than the display face does elsewhere. latin covers English and German in full (ä ö ü ß are all below U+0100); latin-ext exists for ő and ű. An English or German page never downloads latin-ext.

03 — The mark

A chrome paper plane, and one word set in Aboreto.

Stratos

Stratos

Wordmark

Always Aboreto, always uppercase, tracking +0.16em. This is a brand rule, not a typographic preference — it holds on every surface, including new ones, and it is not re-decided per page or per component.

The cursor

On fine pointers the cursor is the logo: a chrome paper plane, 34px, that banks toward its heading and grows to 56px over interactive targets. Disabled entirely on coarse pointers — there is no touch equivalent and faking one is worse than not having it.

Clear space

One plane-width on every side. Nothing enters it: no text, no rule, no crop edge, no other logo.

Don't

Don't recolour the plane. Don't set the wordmark in Archivo, in the mono, or in sentence case. Don't put the mark in a badge or circle. Don't rotate it — the plane's bank angle is driven by motion, and a static tilt reads as a bug.

04 — Geometry & the altimeter

The navigation furniture measures elevation, literally.

The brand's whole argument is altitude, so the signature element is an aircraft altimeter tape that runs the full height of every page. Scroll is the climb. The instrument reads the document's real structure — it is a readout, not an animation.

RAIL — 78px

Fixed left, full height, one hairline on its right edge. Carries the tick tape, the live altitude readout locked to the horizon line, and the layer name. On the homepage the rail is 0px — the climb is the page there, and the instrument is the whole canvas.

GUTTER — clamp(1.25rem, 4vw, 5rem)

One fluid inset for every band. Max content width 1560px, centred.

THE MERIDIAN TRACE — 1.25px

Chrome held back to 32% at rest, signal when the section is live.

FOCUS — 2px signal, 3px offset, 2px radius

One focus style for the whole system. Never removed — tab to the button below to see it.

05 — Motion

One curve. Scroll is the input.

--ease: cubic-bezier(.22, 1, .36, 1)

Everything that moves uses it. There is no second curve.

READOUT, NOT DECORATION

The altimeter reads the document's real structure. If a number on screen is not measuring something, it does not belong.

SNAP, DON'T MORPH

Discrete state changes without overshoot. No liquid interpolation between type states.

COMPOSITE ONLY

State changes transition opacity, transform and max-width — properties that cost a composite, never a reflow of the whole document.

REDUCED MOTION

Everything collapses under prefers-reduced-motion: reduce. No component opts out. This page honours it too.

06 — Components

Square corners, hairline borders, mono labels.

Nothing in this system has a border radius except the 2px on the focus ring. The instrument reads as machined, not soft.

BUTTONS

One signal button per view. The uppercase mono-adjacent tracking is what makes them read as controls on an instrument rather than as web buttons.

FORM

Underline only — no boxes. Label in mono, input in the body face at ≥16px so mobile never zooms on focus.

07 — Voice

A good technical partner in a meeting.

Specific, unhurried, slightly blunt, never impressed with itself. Everything Stratos publishes sits on one idea: the competition is still in the valley. The copy has to earn the altitude the page is claiming.

Do
  • Lead with the outcome, then the mechanism. "More enquiries, because the page loads before they leave."
  • Use real numbers, real place names, real client names.
  • Say the uncomfortable thing when it is true. "Most of your traffic already bounced."
  • Keep sentences short enough to read on a phone at arm's length.
Don't
  • solutions · leverage · synergy · cutting-edge · game-changing · digital transformation · in today's fast-paced world
  • Claim awards, partnerships or certifications that do not exist.
  • Invent metrics. Ever.
  • Write a paragraph where a clause will do.

Hungarian

Source language, and the only one written from scratch. Informal te. Direct, a little dry.

English

International, not American. Plain over promotional. No exclamation marks.

German

Formal Sie. German business writing punishes casualness, so the Hungarian bluntness has to become precision instead.

Translation

EN and DE are generated from the same markup. Translate the intent, not the words — an idiom that lands in Hungarian usually does not survive.
