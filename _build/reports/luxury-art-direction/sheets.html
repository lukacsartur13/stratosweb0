Direction A — Refined neo-grotesk

Archivo at one width and two weights, plus one mono metadata line per frame. Sentence case throughout the brand voice; uppercase survives only in the instrumentation. Every element in every frame begins on a single left spine and the mass sits in the upper third. Monochrome: near-black, off-white, neutral grey. No accent colour, no gradient grading, no animation.

Direction B — Grotesk with a restrained editorial contrast

The same grotesk carries the statements. One Archivo Italic line per frame — a complete thought, never a decorated word inside a sentence — is thrown into counterpoint across the open field, so each frame reads as a diagonal rather than a stack. The mass drops to the middle band. Monochrome throughout.

Direction C — Ultra-minimal Swiss

One family. One weight — 400, and nothing else anywhere in the direction. No mono, no italic, no all-caps at any size including the metadata. Two type styles exist in total: monument and whisper. The monument is set at the variable font's 88% width coordinate for architectural compactness and anchored at the foot of the frame, leaving the upper field empty but for one 16 px line.

All nine frames — the comparison

Directions across, scenes down. Same words, same margin, same instrument, same monochrome palette in all nine: the only variable is the typographic setting. Read the columns to judge a direction, the rows to judge whether a direction holds across three very different jobs. The strip at the foot is the distance test — if the three directions are not still distinguishable there, the exploration was not deep enough.

Locale stress — the same system in German

The high-altitude statement is the binding one: in German it sets 47% wider than in Hungarian at the same size. Nothing below is redesigned for the locale — the type system, the sizes and the composition are the ones from the sheets above. Only the line break moves, and in the last frame the size.
